Checklist para preparar o bot para venda

1) Código e dependências
 - Atualizar `package.json` com versão e scripts (start, test)
 - Remover tokens sensíveis do código
 - Garantir `.env.example` com variáveis necessárias

2) Documentação
 - README com setup passo-a-passo
 - Documentação de comandos e permissões (ex.: `docs/LOJA.md`)

3) Licenciamento
 - Incluir `LICENSE` adequado (MIT/Proprietário)

4) Infra / Deploy
 - Instruções para deploy (Heroku, VPS, Docker)
 - Variáveis de ambiente necessárias

5) Suporte e manutenção
 - Explicar como atualizar comandos (registro global) e backups de DB

6) Comercial
 - Definir TOS e política de reembolso para vendas de licenças
 - Preparar plugin/instalador para clientes
